## Create your own text using this font!
It has some bugs, like that if it overlaps the preview border, it gets cut off, even in the download.

### How to use
1. Download the .zip from releases or our site, that will be linked soon
2. Unzip it
3. Open **index.html**
4. Type whatever you want
5. Hit the download button
